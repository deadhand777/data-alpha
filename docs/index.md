# Data Alpha Portfolio

Documentation for developing, customizing, and contributing to the Data Alpha Portfolio.

Data Alpha is a statically generated portfolio for writing about data, AI, and finance. It uses Astro 7, React 19, TypeScript 6, Tailwind CSS 4, MDX, and Astro Content Collections.

## Start Here

- [Getting Started](./getting-started/) - Install dependencies and run the project locally
- [User Guide](./user-guide/) - Author content and configure the portfolio
- [API Reference](./api-reference/) - Review components, configuration, and Zensical commands
- [Contributing](./contributing/) - Prepare changes and submit pull requests
