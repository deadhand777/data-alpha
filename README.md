# Personal Portfolio Website

A personal portfolio website for data/AI/finance blogging built with Astro 4.0 + React.

## Features

- Astro 4.0 for fast static site generation
- React for interactive components
- Tailwind CSS for styling
- MDX for markdown with JSX support
- TypeScript for type safety
- Sitemap generation
- Deployable to GitHub Pages

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

This site is configured to deploy to GitHub Pages. To deploy:

```bash
npm run build
```
Then push the `dist` folder to the `gh-pages` branch.
