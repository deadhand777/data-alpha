Getting Started¶

Welcome to the Data Alpha Portfolio documentation.

Overview¶

Data Alpha is a statically generated portfolio for writing about data, AI, and finance. It uses Astro 4, React 18, TypeScript, Tailwind CSS, MDX, and Astro Content Collections.

Prerequisites¶

  • Node.js 18 or later and npm for the portfolio
  • Python 3.14 and uv for the documentation site

Run Locally¶

npm install
npm run dev

To preview this documentation in a second terminal:

uv sync
uv run zensical serve
