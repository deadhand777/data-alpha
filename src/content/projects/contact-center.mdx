## Context

Customer-service automation in regulated banking has to do more than produce plausible answers. It must ground product information in evidence, bind access to the authenticated customer, constrain disallowed behavior, and hand control to a human through a predictable path.

## What It Does

A supervisor agent on Amazon Bedrock AgentCore serves an Amazon Connect chat experience. It routes each request through one of three explicit paths:

1. Product questions retrieve cited answers from an S3 Vectors knowledge base.
2. Account-balance requests use server-side identity binding and an MCP gateway for authenticated lookup.
3. Requests that require a person follow deterministic escalation into a human queue.

## Architecture

- Nova 2 Lite provides the foundation model
- Strands Agents structures the supervisor workflow
- Amazon Connect and Lex V2 provide the customer-service channel
- S3 Vectors stores the product knowledge base
- An MCP gateway exposes the authenticated balance capability
- AWS CDK defines the infrastructure in `eu-central-1`

## Guardrails and Evaluation

A Bedrock Guardrail anonymizes personally identifiable information and denies investment advice. A deterministic evaluation harness exercises a golden set of 14 questions; the current implementation scores 14 out of 14 on that set.

This evaluation result is evidence for the covered scenarios, not a claim of unrestricted production readiness.

## Boundaries

This repository is a proof of concept for regulated German banking under BaFin and DORA constraints. Production use would require organization-specific security review, operational controls, scalability work, and regulatory approval.
